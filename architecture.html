SeatFlash — bird's-eye architecture

Local, read-only Finnkino schedule + live seat-map accelerator

Request path

  • Browser asks only the local API.
  • Schedules/layouts usually resolve from RAM.
  • Live seats are fetched only for the selected show.

Speed strategy

  • 7 upstream schedule calls cover 119 site/day views.
  • Stable layouts are deduplicated and preloaded.
  • Volatile availability stays fresh with a 5s TTL.

Safety boundary

  • Local service bound to 127.0.0.1.
  • Runtime token discovery; no credential committed.
  • Read-only: no order, hold, booking, or payment flow.
