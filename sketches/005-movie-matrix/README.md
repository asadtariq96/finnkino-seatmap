## Variant: Movie focus matrix

### Design stance
The movie-first journey at maximum density: pick a movie, see every cinema × every day at once, availability color-coded per cell.

### Key choices
- Layout: 280px movie rail + full-width cinema × day matrix + 420px seat pane
- Cells: time + format + % free, sold-out struck through; legend shows availability bars
- Interaction: one click on a cell → seat map in the right pane; scope toggle (Helsinki / All cities)
- Sticky headers: cinema column and day row stay put while scrolling

### Trade-offs
- Strong at: "where and when can I see THIS movie" in one glance; cross-cinema + cross-day comparison
- Weak at: browsing without a movie in mind (rail is the only entry); horizontal scroll for 7 day columns

### Best for
- The movie-first journey (your flow 1 + flow 2 merged — cinema and day visible simultaneously)
